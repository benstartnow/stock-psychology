# 股市心理博弈｜Selden 市场心理学（stock-psychology）

一个把 G.C. Selden 1912 年经典 **《Psychology of the Stock Market》**（中译《股市心理博弈》/《股市心理操控术》）蒸馏成可操作投研框架的 WorkBuddy skill。

> 核心一句话：**股价的短期波动，主要取决于参与者的心理状态，而不是基本面。**

## 书籍来源

- 书名：*Psychology of the Stock Market*
- 作者：G. C. Selden（G.C. 塞尔登），1912，Ticker Publishing Company
- 公版状态：原作者 1870–?，本书在多数司法辖区已进入公版；本 skill 英文原文取自 Project Gutenberg（eBook #75570）。
- 中译常见名：《股市心理操控术》（金城出版社，于占英 译）、《股市心理博弈》。

## 这个 skill 能做什么

帮你在两件事上不掉坑：

1. **看市场**——识别投机周期处在哪一段、群体是贪婪还是恐惧、利好/利空在当下价格位置意味着什么。
2. **看自己**——识别自己的仓位偏见、执念、固执，把决策从「我想」拉回「市场在哪」。

## 怎么用

在 WorkBuddy 对话中直接描述你的盘面或心理状态即可触发，例如：

- 「为什么这只票出了利好反而跌？」
- 「我现在满仓有点慌，是不是该跑？」
- 「大家都在喊牛市，是不是快到顶了？」
- 「帮我做个交易心态自检 / 市场情绪温度」

skill 会定位你处在投机周期哪一段、读出消息在当下价位的含义、照出你的仓位偏见，并给操作含义（不荐股、不预测点位）。

## 边界

- 心理框架是「滤镜」不是「计算器」，不替代估值 / 技术 / 风控。
- 不承诺收益、不荐股。A股 语境下情绪信号常领先基本面，但需验证流动性与资金结构。
